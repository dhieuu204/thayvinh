# Update 22/04/2026 - Thêm Chức Năng Sale% Cho Sản Phẩm

## Tổng Quan
Cập nhật chức năng quản lý sản phẩm để thêm trường giảm giá phần trăm. Người dùng có thể nhập % giảm giá, hệ thống sẽ tính giá sau sale dựa trên giá bán (nếu có) hoặc giá gốc, với validation đảm bảo giá sau sale không thấp hơn giá gốc.

### 2. Controller - `back-end/main/controllers/ProductController.js`

#### **createProduct** - Tạo sản phẩm mới

**Thêm:**
1. Destructure `saleDiscount` từ `req.body`
2. Validation logic:
```javascript
if (saleDiscount) {
  const discountPercent = Number(saleDiscount);
  const baseForDiscount = Number(salePrice || basePrice);
  const finalPrice = baseForDiscount * (1 - discountPercent / 100);
  if (finalPrice < Number(basePrice)) {
    return res.status(400).json({
      success: false,
      message: `Giá sau khi giảm (${Math.round(finalPrice)}) không được nhỏ hơn giá gốc (${basePrice}).`
    });
  }
}
```
3. Thêm `saleDiscount: saleDiscount || null` vào `Product.create()`

#### **updateProduct** - Cập nhật sản phẩm

**Thêm:**

2. Validation logic tương tự createProduct (có xử lý khi update từng field)
3. Thêm `if (saleDiscount !== undefined) updateData.saleDiscount = saleDiscount;`

**Công thức tính:**
- finalPrice = (salePrice || basePrice) × (1 - saleDiscount/100)
- Validate: finalPrice >= basePrice

#### **useProductForm Hook - Form State**

#### **Validation Function**

**Thêm validation cho saleDiscount:**
```javascript
if (form.saleDiscount) {
  const discountPercent = Number(form.saleDiscount);
  if (discountPercent < 0 || discountPercent > 100) {
    e.saleDiscount = "Giảm giá phải từ 0-100%";
  } else {
    const baseForDiscount = Number(form.salePrice || form.basePrice);
    const finalPrice = baseForDiscount * (1 - discountPercent / 100);
    if (finalPrice < Number(form.basePrice)) {
      e.saleDiscount = `Giá sau giảm (${fmt(finalPrice)}) không được nhỏ hơn giá gốc (${fmt(form.basePrice)})`;
    }
  }
}
```

#### **ProductDrawer (Thêm sản phẩm)**

**Thêm input field:**
```jsx

  <div className="flex gap-2">
    <input name="saleDiscount" type="number" min="0" max="100" value={form.saleDiscount} onChange={handle} placeholder="0-100" className={inputCls(errors.saleDiscount)} />
  </div>
  {form.saleDiscount && !errors.saleDiscount && (

    </p>
  )}
  {errors.saleDiscount && <p className="mt-1 text-[11px] text-[#e53e3e]">{errors.saleDiscount}</p>}
</div>
```
